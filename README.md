# SmartBranch360

### Secure Branch Office Network using Cisco Packet Tracer

SmartBranch360 is a branch-office network simulation designed in Cisco Packet Tracer with **Employee, Guest, Server, and Management VLANs**, inter-VLAN routing, and wireless guest connectivity.

### Key Features

* VLAN segmentation
* Router-on-a-Stick inter-VLAN routing
* Trunk configuration
* Guest Wi-Fi network
* Network connectivity testing
